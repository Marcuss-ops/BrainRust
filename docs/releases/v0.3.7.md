## Assets

The bundle contains the eight assets expected by `rust-fetch`:

1. `pipelinegen-muscles`
2. `visualner`
3. `mediasampler`
4. `semantic-engine`
5. `BRAINRUST_RELEASE.json`
6. `sha256sums.txt`
7. `ICU_MAJOR`
8. `TOOLCHAIN`

`BRAINRUST_RELEASE.json` records the exact `git_sha`, binary digests,
`semantic_schema`, `entity_index`, `mediaexec_schema`, `image_plan_schema`,
`icu_major` and toolchain.

## Install the local bundle

```sh
make rust-fetch \
  RUST_ARTIFACTS_DIR=/path/to/BrainRust/dist-v0.3.7 \
  BRAINRUST_VERSION=v0.3.7 \
  RUST_ICU_MAJOR=72
```

Updating `refactored/make/build.mk` and `refactored/bin/BRAINRUST_RELEASE.json`
is a separate publication/cutover action. This candidate does not change the
production pin.
